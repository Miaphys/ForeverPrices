Get started in 2 minutes

Install the addon

Extract the addon zip into _forever_\Interface\AddOns.

Run the companion

Start ForeverPrices.exe. A gold coin appears by your clock; it finds WoW by itself and keeps prices fresh.

Log in

On Normal and PvP, prices show up right away. On other rulesets, search the auction house once first.

What you see

AH marketThe typical price: average of the cheapest 25% listed, ignoring silly outliers.
AH lowestThe single cheapest listing right now.
AH 3-day avgThe market price averaged over about 3 days, to spot bargains.
StacksBag stacks show the whole stack's price; hold Shift for one.

Why it's different

No scanningPrices come from Blizzard's own hourly auction data for every house.
Your houseEvery Forever auction house is its own market; you see prices from yours.
EU & USBoth regions, switch in the coin's right-click menu.
Open sourceAll code is on GitHub under the MIT license.

Questions

Windows says "Windows protected your PC"

The app isn't code-signed yet (signing certificates cost money), so Windows warns about it. Click More info, then Run anyway. The code is open on GitHub and each release lists the file's SHA-256 fingerprint.

Why do I need the companion app?

WoW addons can't use the internet. The companion downloads the latest prices and writes them where the addon can read them. It's tiny, sits by your clock, and downloads about 0.5 MB an hour.

My prices didn't change while playing

WoW only loads addon data at login or /reload. The coin shows a notification when new prices are ready.

Does it need my Battle.net login?

No. It never touches your account or the game itself; it only downloads public price data and writes one addon file.

For addon authors

Other addons can read the prices: ForeverPrices.GetPrice(item) and more. See the README.
